Usage-based pricing and monetization platform with a REST API for managing meters, pricing plans, customer entitlements, and real-time usage tracking for SaaS products. Octane enables infrastructure and SaaS companies to implement flexible pay-as-you-go billing similar to Snowflake and AWS, with support for counters, metered components, flat-rate schemes, discounts, trials, and add-ons.

**Areas:** Usage-Based Billing · Metered Billing · Pricing Plans · SaaS Monetization · Fintech · Payments · Usage Tracking · Meters · Entitlements

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Octane: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
